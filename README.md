# Java Practice

Small, independent Java exercises for practicing core language features, collections, generics, sorting, iterators, and streams. Most files can be compiled and run on their own with a JDK.

## Topics

| Topic | Example files |
| --- | --- |
| Core Java, loops, and methods | `CoreJavaPractice.java`, `foreach.java`, `m.java`, `prac.java` |
| ArrayList and list algorithms | `Arraylist.java` |
| LinkedList | `linkedList.java` |
| Sets and duplicate handling | `setPractice.java` |
| Maps and HashMap behavior | `MapPractice.java`, `hashmap.java`, `hashMapEquals.java`, `HashMapInternalPractice.java`, `hashmapPractic.java`, `hashMapPractice.java` |
| Generics, bounds, and wildcards | `JavaGenerics.java`, `genericLadderPractice.java`, `genericsPract.java` |
| Comparable and Comparator | `comparablevscomparator.java`, `Comparatordemo.java` |
| Iterators and removal | `practicingiterator.java` |
| Lambdas, streams, and Optional | `needsForStream.java`, `PracticeStream.java`, `StreamPractice.java` |

See [TOPIC_TRACKER.md](TOPIC_TRACKER.md) for the practice and revision checklist.

## Compile and Run

Install a JDK, open a terminal in this directory, then compile and run a class. For example:

```powershell
javac Arraylist.java
java Arraylist
```

The source filenames and public class names are case-sensitive. Some files also define helper classes in the same source file. Generated `.class` files are build output and are not source files.
